Checking if your Python server is running...

🟢 Quick Start (Best Way)

  1. Open your Kutty folder.
  2. Double-Click Start_App.bat

🟠 Alternate Way (Using CMD)

  1. Open your Kutty folder.
  2. Click the Address Bar at the top, type cmd and hit Enter.
  3. Type python app.py and hit Enter!

🔵 Manual Start (For Coders)

  1. Open VS Code Terminal.
  2. Type python app.py and hit Enter.
